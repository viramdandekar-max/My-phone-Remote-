# My Phone Remote — Starter UI

Android Kotlin starter project with one APK, Controller and Receiver selection, and translations in English, Gujarati and Hindi.

**Not yet implemented:** pairing, networking, location, remote ringing, screen sharing, file transfer or remote control. Buttons show a clear starter notice. No sensitive permissions are requested.

## Build from GitHub
Upload all project files preserving folders to a new GitHub repository. Open Actions > Build Android APK > Run workflow. Download the APK artifact after a successful run. The artifact contains a debug APK for testing, not a production release.

Remote features in later versions must use explicit consent, visible active-session indicators and revocable permissions.
